One line: a one-star review of Monday, written as if Monday were a restaurant, in 21 words. The program writes it to `/output/entry.txt`:

> Sat down Monday, stood up Friday: cold coffee, a 9 a.m. meeting, and a bill for the whole week. One star.

## Run it

```sh
python3 main.py
```
